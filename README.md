1.- Cada integrante del grupo creo un repositorio en su cuenta personal de github.
2.- Creamos una branch con nuestro nombre en el repositorio en la que creamos un archivo de java (HolaMundo)
3.- Luego seleccionamos un repositorio para crear los distintos branch (4) y agregar nuestro programa de java.
4.- Posteriormente le hicimos un cambio y hicimos commit del mismo.
5.- Luego hicimos un merge de cada branch en la que nos dio un conflicto ya que los archivos tenían el mismo nombre.
6.- Juntamos ambos archivos, así para cada una de las distintas branch hasta terminar con una fusión de las 4.

Al principio nos costó crear el repositorio ya que lo estabamos haciendo desde github, pero se nos facilito al crearlo desde directamente desde Intellij IDEA.
También nos paso de que subimos el archivo a master al principio, y no creamos nuestra branch.
Nos dimos cuenta de que al tener una versión distinta de java entre algunos integrantes, nos daba conflicto. (pom.xml) creado desde la estructura Maven.
Nos costó subir el archivo en un principio a github.

Gracias a esta actividad comprendimos como usar y como prevenir ciertos errores que se nos pueden presentar al realizar el proyecto en Intellij IDEA y GitHub de manera colaborativa, para así desarrollar nuestro proyecto de una manera más eficaz y efectiva.
Y también aprendimos a usar la herramienta merge para combinar archivos o decidir que cosa se queda y que no.
